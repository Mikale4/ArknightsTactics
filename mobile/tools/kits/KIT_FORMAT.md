# Operator kit format (real Arknights kits, translated to turn-based)

`mobile/src/a3b_real.js` holds every operator's real skills and talents, translated from the Arknights game data
into this game's turn-based rules. It is generated by `python mobile/tools/merge_kits.py build` from the JSON files in
`mobile/tools/kits/` (one object per operator) plus `mobile/tools/real.json` (game data from `extract_kits.py`).
Validate a file with `python mobile/tools/merge_kits.py check mobile/tools/kits/<file>.json`.

## Battle rules the kits translate into

* Turn-based ATB battle: units act in order of SPD. A "turn" below always means **the operator's own turn**.
* Every operator has a **basic attack** given by their branch trait (see `BRANCH` in `a3c_kits.js`). Kits don't define it.
* Real skills S1/S2/S3 unlock at Elite 0/1/2 (from the data). Each has a **cooldown in turns**.
  `cd` and `cd0` (starting cooldown) are computed by the merge tool from SP cost and initial SP. Don't write them.
* **Damage**: `damage = ATK × mult × 3 (turn scale) × mitigation`.
  `mult` uses the **real Arknights multiplier**: 1 = one normal attack (100% ATK). Write the real numbers.
  * `phys` (Physical): reduced by DEF. `arts` (Arts): reduced by RES (0–100 points, percent). `true`: not reduced.
  * Default damage type: Casters, Supporters, Medics and Arts Fighters → `arts`; everyone else → `phys`.
* **Healing**: `heal: x` heals `ATK × x × 3`. Use the real multiplier (heal 100% ATK → `1`).
* **Duration skills** become a **state** that lasts `turns` of the operator's normal turns of time, **including the
  turn the skill is used** (it's timed like Arknights seconds, so SPD boosts fit more actions into the state).
  Using a state skill also performs the (modified) basic attack in the same turn, so the turn isn't wasted.
  The merge tool supplies a suggested `turns` from the real duration (about 8 seconds per turn). Use it unless the
  skill clearly needs otherwise. A skill's cooldown doesn't count down while its own state is active.
  Infinite-duration skills (toggles) use `turns: 99`.
* Statuses tick down at the end of the affected unit's own turn. Crowd control usually lasts 1 turn.
* Translating tower-defense concepts:
  * **DP** gained → team turn meter (`atkbar+` on `team`): about 0.04 per DP, capped at 0.3.
  * **Block** → enemies prefer to attack high-Block operators (automatic; don't translate block changes,
    except "Block +N" may become `taunt: true` when it's the point of the skill).
  * **Attack range** expansion → ignore, or `reach: true` (can target past Taunt/Camouflage) when range is the point.
  * **ASPD** (attack speed) +X → `spd: X/100 × 0.6` (e.g. ASPD +100 → `spd: 0.6`). Reduced attack interval works the same way:
    interval −0.5s on a 1.0s attacker ≈ `spd: 0.5`.
  * **"Attacks N times / N targets"** → `hits` / `n`.
  * **"Next attack"** skills → an instant action (not a state).
  * **Shift / Push / Pull** (Hookmasters, Push Strokers, Specialists) → `atkbar-` on the target (0.1–0.3) and/or `STUN`/`BIND`.
  * **Aerial enemies** → there are none; drop the condition or apply the effect to all targets.
  * **Redeploy time, deployment cost, tiles, terrain** → drop.
  * **"Allies within range"** → `team` (or `allies` if it excludes self). **"Enemies within range"** → `enemies`.
  * **Summons / devices / drones** → `summon` (see below), or fold into the skill as extra hits.
  * **Elemental damage** (Burn, Necrosis, Nervous Impairment, Corrosion) → `elem` effect.
  * **Taunt level / "more likely to be attacked"** → `TAUNT` buff (single-target attacks must hit this unit).
  * **Camouflage / Invisible / "less likely to be targeted"** → `STEALTH`.
  * **"Resist damage" / Dodge** → `DODGE` (chance to fully avoid physical and Arts hits).
  * **Barrier / Shield (absorbs damage)** → `shield`.
  * **"Doesn't retreat when HP reaches 0" / "Undying"** → `special: "UNDYING"` or `INVINCIBLE` buff for short windows.

## Operator object (one per operator, in the kit JSON files)

```json
{ "slug": "exusiai",
  "skills": [ SKILL, ... ],      // exactly the real skills, in order (S1, S2, S3). Names: official EN names.
  "talents": [ TALENT, ... ] }   // exactly the real talents, in order. Names: official EN names.
```

## SKILL

```jsonc
{
  "name": "Overloading Mode",
  "desc": "Auto. For 2 turns, basic attacks fire 5 shots (110% ATK each) and SPD +10%.",  // our-game text, ≤ 160 chars, Lv7 values
  "auto": true,           // optional: real skill is "Auto Trigger". Instant auto skills replace the next basic attack
                          //           automatically when ready; state auto skills activate automatically at turn start.

  // ---- instant action (optional) ----
  "target": "enemy",      // enemy | enemies | aoe_enemies | ally_single | self | team | allies
                          // enemies = the chosen enemy plus up to n-1 others; aoe_enemies = every enemy
  "n": 3,                 // max targets for "enemies"
  "spread": true,         // each hit lands on a random enemy ("fires N times at random targets")
  "hits": 1,              // hits per target
  "mult": 2.2,            // real ATK multiplier per hit (0/omitted = no damage)
  "dmg": "arts",          // phys | arts | true (omit = operator default)
  "ignoreDef": 0.5,       // fraction of target DEF ignored (flat DEF ignore → ~0.3–0.6; "ignores DEF" → 1)
  "ignoreRes": 0.3,       // fraction of target RES ignored
  "heal": 1.5,            // heal targets (ally_single/team/allies/self) for ATK × 1.5
  "effects": [ EFFECT, ... ],

  // ---- duration state (optional, may combine with an instant action) ----
  "state": STATE,

  // ---- passive skill (real skill type PASSIVE) ----
  "passive": TALENT       // the skill is always on once unlocked (no button); use TALENT fields
}
```

Rules: a skill needs at least one of: damage (`mult`), `heal`, `effects`, `state`, or `passive`.
If a skill has a `state` and no `mult`/`heal`, using it applies the state and then performs the modified basic attack.
Set `"basic": false` on skills that stop attacking: no basic attack on the turn it is used or while its state lasts (heal-mode basics from `state.basic.heal` still heal).

## STATE (while a duration skill is active)

All fields optional.

```jsonc
{
  "turns": 2,
  // stat changes (fractions unless noted)
  "atk": 0.9, "def": 0.65, "hp": 0.3 /* max HP, also heals by that amount */, "spd": 0.3,
  "cr": 0.2 /* crit rate */, "cdmg": 0.3 /* crit damage */, "ares": 20 /* Arts RES points */,
  "res": 0.2 /* status resistance */, "dodge": 0.5, "dmgTaken": -0.3 /* takes 30% less damage */,
  "regen": 0.05 /* heals 5% max HP at the start of each turn */, "lifesteal": 0.2,
  "taunt": true, "stealth": true, "counter": 0.5 /* chance to counter with basic attack when hit */,
  "reflect": 0.8 /* deals ATK × 0.8 Physical (or reflectDmg) back to each attacker */, "reflectDmg": "arts",
  "immune": true /* Immunity: can't receive new debuffs */,
  "invincible": true /* takes no damage — only for very short real windows */,
  "drain": 0.05 /* loses 5% max HP at the start of each own turn (true damage, can't kill) */,
  "onEnd": [ EFFECT, ... ] /* applied when the state ends, e.g. self STUN, or {"on":"self","type":"retreat"} */,
  // basic attack while active (fields replace the branch basic attack's fields; effects are added)
  "basic": { "hits": 5, "mult": 1.1, "n": 3, "aoe": true, "spread": true, "dmg": "arts", "ignoreDef": 0.3, "ignoreRes": 0,
             "heal": 0.75 /* basic attack heals the lowest ally instead */, "healN": 3 /* heals N lowest allies */,
             "reach": true, "falloff": 1 /* chain falloff */, "front": 1.5 /* main-target multiplier */, "effects": [ EFFECT, ... ] }
}
```

## EFFECT

```jsonc
{ "on": "target",   // target (the hit/selected unit) | self | team (all allies incl. self) | allies (other allies)
                    // | enemies (all enemies) | lowest (lowest-HP ally) | attacker (who hit us; "hurt" talents)
                    // | random_enemy
  "type": "debuff", // see below
  "chance": 0.5 }   // optional, default 1
```

| type | fields | meaning |
|---|---|---|
| `buff` | `what`, `turns`, `v` | give a buff (table below). `v` = magnitude |
| `debuff` | `what`, `turns`, `v`, `chance` | inflict a debuff (can be resisted) |
| `dmg` | `mult`, `dmg`, `hits` | extra damage instance (talents like "deals 50% ATK Arts damage") |
| `heal` | `amount` | heal ATK × amount |
| `healPct` | `amount` | heal a fraction of the receiver's max HP |
| `shield` | `amount` *or* `pctHP`, `turns` | Barrier: ATK × amount, or caster max HP × pctHP |
| `atkbar+` / `atkbar-` | `amount` | turn meter ± fraction (0.1 = 10%) |
| `cleanse` | `amount` | remove debuffs |
| `strip` | `amount` | remove buffs |
| `revive` | `amount` | revive one fallen ally at amount × max HP |
| `cdReduce` | `amount` | reduce receiver's skill cooldowns by N turns |
| `elem` | `kind`, `amount` | build elemental injury: `burn` / `necrosis` / `nervous` / `corrosion`; `amount` 0–1 of the gauge. Bursts at 1 |
| `bonusIf` | `cond`, `bonusDmg`, `bonusCrit` | (skill effects only) more damage if the target has status `cond` |
| `bonusPerDebuff` | `per`, `cap` | (skill effects only) +per damage per debuff on the target |
| `retreat` | | (only `on: self`, usually in `onEnd`) the operator leaves the battle |

Any effect may carry `"onKill": true` (skills only: applies only if the action defeated its target), e.g.
Surtr S1 "if the target is defeated, recover all SP" → `{"on":"self","type":"cdReduce","amount":9,"onKill":true}`.
`on` may also be `random_ally` (one random other ally).

Elemental bursts: burn = 12% max HP true damage and RES −20 (2T); necrosis = 10% max HP true damage and ATK Down (2T);
nervous = 8% max HP true damage and Stun (1T); corrosion = DEF −30% (2T).

### Buffs (`what`, default `v`)
`ATK_UP` (.3), `DEF_UP` (.3), `SPD_UP` (.3), `CRIT_RATE_UP` (.3), `RES_UP` (20 points), `IMMUNITY`, `HOT` (.05 max HP/turn),
`INVINCIBLE`, `COUNTER` (.3 chance), `TAUNT`, `STEALTH` (Camouflage), `DODGE` (.3), `DMG_REDUCE` (.3, Shelter),
`INSPIRE` (.15, Inspiration: the receiver gains flat ATK equal to v × the giver's ATK).

### Debuffs (`what`, default `v`)
`DEF_BREAK` (.3, shown "DEF Down"), `ATK_DOWN` (.3), `RES_DOWN` (20 points), `FRAGILE` (.2, takes more damage),
`SLOW` (.3 SPD), `COLD` (.3 SPD; Cold again → Freeze), `BIND` (.5 SPD, shown "Bind"), `STUN`, `SLEEP` (skips a turn,
wakes when damaged), `FREEZE` (skips a turn, RES −15), `LEVITATE` (skips a turn), `SILENCE` (no S1–S3),
`HEAL_BLOCK`, `DOT` (Burn: 5% max HP per stack per turn, `v` overrides), `FEAR` (can't use S1–S3, SPD −30%).

## TALENT (also used for passive skills)

```jsonc
{
  "name": "Fast Cartridge",
  "desc": "SPD +9%.",           // our-game text, ≤ 160 chars
  // permanent self stats (applied when the talent is unlocked):
  "stats": { "atk": 0.08, "hp": 0.13, "def": 0.1, "spd": 0.09, "cr": 0.1, "cdmg": 0.2, "ares": 10, "res": 0.1,
             "dodge": 0.2, "dmgTaken": -0.1 },
  // permanent stats for others at battle start:
  "aura": { "who": "team" /* team | allies | random_ally | class:Defender | melee | ranged | enemies */, "stats": { "def": 0.08 } },
  // ("enemies" auras debuff every enemy wave, e.g. Ifrit's RES −44%: { "who": "enemies", "stats": { "aresPct": -0.44 } })
  // conditional stats (re-checked every time): applied while `while` holds
  "while": { "hpBelow": 0.5 }, "whileStats": { "atk": 0.3 },
  // conditional damage bonus on own attacks
  "dmgBonus": [ { "cond": { "targetHpBelow": 0.5 }, "v": 0.3 } ],
  // conditional damage reduction on hits taken
  "dmgReduce": [ { "cond": { "attackerRanged": true }, "v": 0.2 } ],
  // triggered effects
  "on": "attack",               // start | wave | turn | attack | hit | hurt | kill | skill | allyDeath | lowhp
  "cond": { "targetHas": "STUN" },
  "chance": 0.3, "once": true, "every": 3 /* every 3rd trigger */,
  "effects": [ EFFECT, ... ],
  // more triggers in the same talent (each: on, cond, chance, once, every, effects)
  "triggers": [ { "on": "kill", "effects": [ { "on": "self", "type": "cdReduce", "amount": 1 } ] } ],
  // engine specials
  "special": "UNDYING", "amount": 0.3, "turns": 1
}
```

Stat keys (in `stats`, `whileStats`, `aura.stats`, state): `atk`, `def`, `hp`, `spd` are percent changes (0.1 = +10%);
`cr`, `cdmg`, `res`, `dodge` add flat fractions; `ares` adds RES points; `aresPct` scales RES (−0.44 = RES −44%);
`dmgTaken` (−0.2 = takes 20% less damage); `heal` (+0.2 = heals 20% more).

**SP talents** ("restores SP", "SP recovery +X/s") → `cdReduce`: e.g. "+1 SP per attack" ≈ 30% chance per `attack`
to reduce own cooldowns by 1; "allies' SP recovery +0.3/s" ≈ `on: "turn", "every": 3, effects: [cdReduce team 1]`.

Triggers: `start` battle start · `wave` each new enemy wave after the first · `turn` start of own turn · `attack` after an own action
that damaged an enemy (target = main target) · `hit` each damaging hit (target = hit unit) · `hurt` when damaged
by an enemy (attacker = them) · `kill` defeated an enemy · `skill` after using S1–S3 · `allyDeath` an ally falls ·
`lowhp` HP first drops below `cond.hpBelow` (once).

Conditions (`cond` / `while` / dmgBonus `cond`): `hpBelow`, `hpAbove`, `targetHpBelow`, `targetHpAbove`,
`targetHas` (status id), `targetDebuffed`, `targetBoss`, `selfHas` (status id), `skillActive` (true/false),
`attackerRanged`, `attackerMelee`, `alliesAlive` (≥ N), `enemiesAlive` (≥ N).

Specials: `UNDYING` (once per battle: survive a lethal hit at `amount` × max HP, then `INVINCIBLE` for `turns`),
`REVIVE_ONCE` (same as UNDYING, legacy), `LIFESTEAL` (`amount`), `NO_ALLY_HEAL` (can't be healed by others),
`IMMUNE_LIST` (`list` of status ids), `TRUESIGHT` (can target Camouflaged/Stealthed enemies).

## Writing descriptions

* Short, concrete, our terms: "turn(s)", "turn meter", "SPD", "RES", "Physical/Arts damage", "allies", "enemies".
* Write the Lv7 (or best talent) numbers you used: "For 3 turns: ATK +95%, DEF +60%, basic attacks hit up to 3 enemies."
* Don't mention tiles, range, DP, deployment, redeploy, aerial, blocking.
